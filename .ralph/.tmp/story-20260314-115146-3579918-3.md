### US-003: Strengthen preflight and checkpoint readiness checks
Status: in_progress
Depends on: US-002

Description:
As an ML engineer, I want preflight to catch missing data or checkpoints before training begins.

Acceptance Criteria:
- [ ] Preflight validates dataset split counts and expert presence for required experts
- [ ] Example: valid manifest produces non-empty dataset_report.json and checkpoint_report.json
- [ ] Negative case: missing expert checkpoint set aborts run with explicit expert name and source path
- [ ] Checkpoint stage records successful/failed per expert with deterministic path
