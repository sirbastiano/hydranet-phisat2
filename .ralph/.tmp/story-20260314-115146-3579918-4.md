### US-004: Stabilize startup gate diagnostics
Status: in_progress
Depends on: US-003

Description:
As a maintainer, I want actionable startup gate failures so environment issues are quickly triaged.

Acceptance Criteria:
- [ ] Record startup gate status and timeout in startup_gate.json
- [ ] Example: import probe failure includes timeout_seconds and traceback
- [ ] Negative case: timeout or missing import does not proceed to fit and records explicit `startup_failed`
- [ ] startup_log.txt includes stage transitions and timestamps
