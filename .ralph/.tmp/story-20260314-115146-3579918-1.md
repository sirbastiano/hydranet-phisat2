### US-001: Define full-training orchestration contract
Status: in_progress
Depends on: None

Description:
As an engineer, I want a written full-training contract so every run follows the same stages and artifacts.

Acceptance Criteria:
- [ ] Document canonical run stages: preflight, startup gate, training, export, smoke
- [ ] Example: a failure in startup stage is recorded as `fit_started` and includes config path and stage log
- [ ] Negative case: a malformed or missing manifest exits before starting long-running tasks
- [ ] Record and validate expected artifact names in `outputs/moe/<timestamp>/summary.json`
