### US-005: Add non-finite loss safeguards during fit
Status: in_progress
Depends on: US-004

Description:
As an ML engineer, I want unstable training to stop with batch-level diagnostics instead of silently exporting invalid checkpoints.

Acceptance Criteria:
- [ ] Detect NaN or Inf loss and abort with batch index, sample id, expert context, and config snapshot
- [ ] Example: a NaN event is written to summary and startup logs before cleanup
- [ ] Negative case: run must not mark success or emit a bundle when NaN is detected
- [ ] Error entry includes `error_type` and `failure_stage` values
