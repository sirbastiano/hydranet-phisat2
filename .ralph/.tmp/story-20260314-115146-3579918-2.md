### US-002: Create a one-shot full-training command path
Status: in_progress
Depends on: US-001

Description:
As an operator, I want one command to run full training from end-to-end without manual intermediate scripting.

Acceptance Criteria:
- [ ] Provide command target or script that executes full flow in a single invocation
- [ ] Example: output directory is created with runtime, config, and report artifacts
- [ ] Negative case: missing required arguments fails with clear usage and no partial run artifacts
- [ ] If any stage fails, exit code is non-zero and failure_stage is written
